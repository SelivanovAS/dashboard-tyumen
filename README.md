# СберСуд · Тюменская область

Мониторинг гражданских дел ПАО Сбербанк: основная картотека и раздел «Иски банка».
Территория использует собственные данные, Worker/KV, VAPID-пару и ключи доступа.
Код выбирает `REGION=tyumen`, браузерное хранилище — `STORAGE_NS=tyumen`.
ХМАО и ЯНАО в её охват не входят.

Реестр по списку пользователя: 24 суда первой инстанции, Тюменский областной суд
(апелляция) и Седьмой кассационный суд общей юрисдикции. Мировые участки и президиум
облсуда отдельно не подключены. Состав и исходные ссылки сохранены в
[реестре](docs/regions/tyumen_courts.json).

## Как поступают дела

Из 26 источников поиск 25 местных судов закрыт капчей. Операторы вводят код на сайте суда и загружают
сохранённую выдачу через операторскую **не реже раза в неделю по каждому суду**.
VPS по расписанию проверяет прямые карточки известных дел. Проверка
карточек не заменяет загрузку свежей выдачи: сама по себе она не обнаруживает
новые дела закрытого поиска. Для Седьмого КСОЮ предусмотрен автоматический сбор с отбором
дел Тюменской области.

Первичное наполнение выполняют операторы; данные других территорий не переносятся,
массовая загрузка исторического портфеля не предусмотрена. Обе картотеки
заполняются по существующим правилам приёма.

Порядок загрузки, исправления ошибок и контроля полноты — в
[инструкции оператора](docs/regions/Тюмень_оператор.md).

## Адреса и исполнитель

Ресурсы территории:

- [Публичный репозиторий](https://github.com/SelivanovAS/dashboard-tyumen) создан.
- [Дашборд](https://selivanovas.github.io/dashboard-tyumen/sberbank_dashboard.html)
  опубликован через GitHub Pages из `main` и проверен в браузере.
- [Worker и операторская](https://api-tyumen.delosud.ru/admin) опубликованы.
- [Дополнительный вход API2](https://api2-tyumen.delosud.ru/admin) через VPS:
  вход и роли проверены без VPN. Для крупных плохо сжимающихся дампов сохраняется
  ограничение передачи; подробности — в [документе API2](docs/regions/Тюмень_api2.md).
- Резервный адрес опубликованного Worker:
  `https://court-monitor-tyumen.7selivanov-a.workers.dev`.

Основной исполнитель — VPS Рег.облако (REG.RU), отдельный клон
`/opt/court-monitor/dashboard-tyumen`. Тюмень включена четвёртой территорией
в общее расписание; четыре таймера `court-*` проверены и включены.
Утренний обход — по будням, доставка — с 08:45 по Екатеринбургу, проверка очереди
импорта — каждые пять минут по будням с 08:00 до 20:55. В выходные очередь ждёт
буднего дня либо разового запуска владельцем. Mac — только ручной резерв.

Состояние на 20.09.2026: код и сайт опубликованы, отдельный
`court-monitor-tyumen` работает. Настроены шесть GitHub Secrets и три Variables;
ручная проверка авторизации OpenRouter, Worker и личного Telegram-чата прошла
без отправки сообщений. Реальная рассылка и первый полный утренний прогон ещё
не подтверждены. Разовый импорт обработал 3/3 дампа; 23 новых дела опубликованы
на Pages. Это не подтверждает полный цикл первичной загрузки именно через API2
без VPN.

Telegram настроен только для личного чата владельца с существующим ботом.
Отсутствующий Worker `GITHUB_PAT` ограничивает статусы и ручное управление
GitHub из админки; автоматическому расписанию VPS не мешает.
