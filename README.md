# СберСуд · Тюменская область

Мониторинг гражданских дел ПАО Сбербанк: основная картотека и раздел «Иски банка».
Территория использует собственные данные, Worker/KV, ключи доступа и браузерное
хранилище. ХМАО и ЯНАО в её охват не входят.

Реестр по списку пользователя: 24 суда первой инстанции, Тюменский областной суд
(апелляция) и Седьмой кассационный суд общей юрисдикции. Мировые участки и президиум
облсуда отдельно не подключены. Состав и исходные ссылки сохранены в
[реестре](docs/regions/tyumen_courts.json).

## Как поступают дела

Поиск местных судов закрыт капчей. Операторы вводят код на сайте суда и загружают
сохранённую выдачу через операторскую **не реже раза в неделю по каждому суду**.
После подключения VPS парсер регулярно проверяет прямые карточки известных дел. Проверка
карточек не заменяет загрузку свежей выдачи: сама по себе она не обнаруживает
новые дела закрытого поиска. Для Седьмого КСОЮ предусмотрен автоматический сбор с отбором
дел Тюменской области.

Картотека начинает работу без дел других территорий. Первичное наполнение
выполняют операторы; автоматическая массовая загрузка исторического портфеля
не предусмотрена. Обе картотеки заполняются по существующим правилам приёма.
Дайджест предназначен только для личного чата владельца с существующим ботом.

Порядок загрузки, исправления ошибок и контроля полноты — в
[инструкции оператора](docs/regions/Тюмень_оператор.md).

## Сопровождение

Код выбирает `REGION=tyumen`, фронтенд — `STORAGE_NS=tyumen`.
При обновлении общего кода сохраняются настройки территории, README и данные.
Новые файлы при merge проверяются отдельно: `merge=ours` их не защищает.
