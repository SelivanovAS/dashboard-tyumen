API2 проксирует запросы к существующему `api-tyumen.delosud.ru`; новые ключи,

Отдельный сервис `court-monitor-upload-tyumen.service` включён и работает
на `127.0.0.1:8787`. В Worker через Cloudflare UI опубликовано
`IMPORT_GATEWAY_ORIGIN="https://api2-tyumen.delosud.ru"`. Обратная загрузка
использует gzip и буферизацию nginx. Пробы с 1 КиБ, 400 КиБ и 2 МиБ

данные в очередь не добавлялись. Это не гарантирует передачу каждого большого

конфигурации дали 502 по таймауту Worker через 20 секунд. Ограничение передачи
крупных плохо сжимающихся дампов сохраняется. Успешный вход в операторскую
не подтверждает полный рабочий цикл без VPN для всех файлов.
Локально прошли 17 тестов сервиса
и 58 тестов шлюза Worker. Подробности и порядок отката —
в [документе API2](../../docs/regions/Тюмень_api2.md).

## Разовый импорт только Тюмени

Команда на VPS под `root` запускает штатный импортёр с общей блокировкой
клона, обработкой текущей очереди, публикацией данных и отчётами оператору:

```bash
systemd-run --unit="court-tyumen-import-manual-$(date +%Y%m%d%H%M%S)" \
  --property=Type=exec --property=User=root \
  --property=WorkingDirectory=/opt/court-monitor/dashboard-tyumen \
  /bin/bash -c 'source /opt/court-monitor/dashboard-tyumen/ops/vps-run/vps_env.sh; exec bash /opt/court-monitor/dashboard-tyumen/ops/mac-local-run/import_dumps.sh /opt/court-monitor/dashboard-tyumen --anywhere'
```

`User=root` задаётся явно: без него у transient-службы при первой пробе
не оказалось `HOME`, и скрипт завершился до чтения очереди. Команда не запускает
общие `court-import.service`/`court-delivery.service` и дайджест; штатный
импортёр может отправить служебный Telegram-алерт при ошибке.
Не добавлять `--force`: у импортёра такого флага нет.

Результат проверять по `ops/mac-local-run/import_dumps.log` в клоне
(строка «Готово: обработано N из M»), статусам и счётчикам заданий в операторской,
публикации картотеки на сайте. Одного кода выхода недостаточно: занятая
блокировка тоже приводит к штатному пропуску.

  для крупного плохо сжимающегося дампа воспроизведён таймаут. Обработка трёх
  реальных заданий на VPS подтверждена; первичная загрузка через API2 — отдельно.
- Первый полный плановый прогон и фактическая доставка Telegram/Web Push
  ещё не проверены; разовый импорт их не запускал.
  Проверка авторизации не подтверждает генерацию модели или доставку уведомлений.
- Чтение карточек проверено в рамках трёх импортированных выдач. Это не
  подтверждает доступность всех остальных судов и всех карточек территории.
