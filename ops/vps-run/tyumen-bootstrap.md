## GitHub и доставка

Настройки доставки ещё требуется подключить. Variables: `REGION=tyumen`,
`DASHBOARD_URL` из таблицы, согласованный
`LLM_PROVIDER` и параметры модели/отбора по действующей схеме проекта.

Secrets: ключ используемого LLM-провайдера, `TELEGRAM_BOT_TOKEN`,
`TELEGRAM_CHAT_ID_TEST`, `PUSH_WORKER_URL`, `PUSH_SECRET`, `PROGRESS_SECRET`,
`VAPID_PRIVATE_KEY`. Для резервного LLM добавить соответствующий ключ.
`TELEGRAM_CHAT_ID_TEST` — существующий **личный чат пользователя с ботом**.
Секрет корпоративной доставки `TELEGRAM_CHAT_ID` не переносить из другой
территории. Если он требуется для всех веток workflow, использовать тот же
личный chat ID: согласована доставка только пользователю.

Первоначальные данные предоставляют операторы. Не запускать массовый сбор
истории или рассылку в другие чаты в качестве проверки подключения.

## Настройки существующего VPS

Подключение ниже предстоит после получения SSH-доступа; добавление территории
в действующие службы и проверка таймеров пока не выполнены.

Использовать отдельный deploy key с правом записи для Git репозитория Тюмени.
В SSH-конфигурации VPS добавить выбор этого ключа для нового клона, сохранив
настройки остальных территорий. Имя файла сверить с фактически созданным ключом:

```sshconfig
Match host ssh.github.com exec "test $(pwd) = /opt/court-monitor/dashboard-tyumen"
  IdentityFile ~/.ssh/deploy_tyumen
  IdentitiesOnly yes
```

Затем подготовить региональные файлы в каталоге конфигурации исполнителя:

- `env.tyumen`: `REGION=tyumen`, `DASHBOARD_URL` из таблицы, `BANK_TRACK=1`
  и применяемые параметры отбора. Токены Telegram/VAPID сюда не добавлять.
- `worker.tyumen`: собственные `url=`, `owner_secret=`, `push_secret=`;
  файл читается как данные, не через `source`.
- `progress_token.tyumen`: отдельный токен прогресса Тюмени.
- `territories`: добавить путь нового клона, сохранив действующие территории.
- Общий файл `telegram` для служебных алертов: проверить, что его получатель —
  личный чат владельца; не менять получателей других территорий попутно.

Секретные файлы имеют права `0600` и не попадают в Git. В копии задать
`git config merge.ours.driver true`. Mac не включать вторым автоматическим
исполнителем. При проверке текущих служб использовать общий
[VPS README](README.md), а не считать наличие файлов подтверждением таймеров.

Проверки подключения: отдельные адреса/ключи, пустые данные Тюмени,
26 записей реестра, выбор региона в настоящем окружении VPS, доступ к поиску
7КСОЮ и прямым карточкам местных судов, импорт тестовой выдачи оператором,
дедуп повторной выдачи, публикация Pages. Сообщение в личный чат и Web Push
фиксируются отдельными результатами, только если фактически проверены.
