# Тюменская область: загрузка дел оператором

В работе 26 судов из исходного списка: 24 районных/городских суда,
Тюменский областной суд (апелляция) и Седьмой КСОЮ. ХМАО и ЯНАО относятся
к другим территориям. Мировые участки и президиум отдельно не подключены.

Основная операторская — `https://api-tyumen.delosud.ru/admin`, дополнительный
вход — `https://api2-tyumen.delosud.ru/admin`. Оба входа используют одни данные
и ключи ролей Тюмени; рабочую ссылку с ключом передаёт владелец. Ключи других
территорий не используются. Вход через API2 работает без VPN; включён отдельный
сервис загрузки, но крупные плохо сжимающиеся файлы могут завершаться ошибкой:
[состояние и особенности API2](Тюмень_api2.md).

## Первый ввод и регулярное обновление

Первичную картотеку наполняют операторы из выдачи судов. Массового автоматического
импорта истории при запуске нет. Новые дела из местных судов поступают только
после загрузки их выдачи; Седьмой КСОЮ проверяется автоматически.

**Не реже одного раза в неделю обновляйте выдачу каждого из 25 местных судов**,
включая апелляцию областного суда. Участие банка проверяется по существующим
правилам: иски против банка попадают в основную картотеку, подходящие иски банка —
в отдельный трек. Капчу вводит оператор на сайте суда.

1. Откройте операторскую Тюмени и укажите своё имя в поле «Вы».
2. Выберите суд и нужный раздел. Для областного суда используйте апелляцию.
3. Откройте поиск по ссылке рядом с судом, найдите дела по слову «Сбербанк»
   и введите проверочный код.
4. Сохраните страницу результатов как «только HTML» либо выделите и скопируйте
   выдачу со ссылками, затем вставьте её в поле импорта. Обычный текст без ссылок
   на дела не подходит.
5. Загрузите необходимые страницы по отдельности. Если за период после прошлой
   проверки появилось больше одной страницы, одной первой страницы недостаточно.
   Повторная загрузка уже обработанной страницы допустима.
6. Нажмите «Отправить на импорт» и проверьте результат задания и построчный отчёт.
   Принятие файла в очередь ещё не означает, что дела уже добавлены.

Очередь автоматически обрабатывается по будням: VPS проверяет её каждые пять
минут с 08:00 до 20:55 по Екатеринбургу. В выходной задание ждёт следующего
буднего дня; вне рабочего окна — следующего запуска по расписанию. Владелец
может разово запустить импорт очереди Тюмени вне расписания. Занятость парсера
этой территории также откладывает импорт.

## Контроль результата

- **Добавлено** — дело поступило в соответствующую картотеку.
- **Связано** — новая инстанция присоединена к известному делу.
- **Уже отслеживается** — дело было загружено ранее.
- **Другой регион** — источник не относится к Тюменской области; такие результаты
  возможны в общей выдаче Седьмого КСОЮ.
- **Требует проверки** — суд, номер или УИД не позволили надёжно связать записи.
  Передайте владельцу ссылку на карточку и номер задания импорта.
- **Карточка не прочиталась** — повторите ту же выдачу после восстановления сайта.
  Иск против банка может ожидать дочитки. Иск банка, апелляция и кассация требуют
  успешной проверки карточки для приёма.
- **Дамп другого суда/раздела** — выберите соответствующий источник и повторите
  загрузку.

Свежесть выдачи и свежесть карточек — разные показатели. Автоматическая проверка
уже известных дел не обнаруживает новые дела за капчей и не заменяет еженедельную
работу с выдачей. Нулевой результат поиска проверьте на сайте суда; страницу
капчи или сообщения об ошибке нельзя считать подтверждением отсутствия дел.

Дайджест направляется только в личный чат владельца с существующим ботом.
Операторский доступ сам по себе не подписывает других людей на Telegram-рассылку.
